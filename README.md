## Инструкция по установке и использовании функции
Менеджер проектов: `poetry`
- `poetry init` - Инициализировать пакет в сущестующем проекте.  
- `poetry new package-name` - Создать новый проект.  
- `poetry shell` - Активировать виртуальное окружение.
- `exit` - Выход.

Необходимы форматеры:  
1. flake8
- `poetry add --group dev flake8` - установка  
2. isort  
- `poetry add --group dev isort` - установка   
3. mypy  
- `poetry add --group dev mypy` - установка  
4. black  
- `poetry add --group dev black` - установка  
5. pytest  
- `poetry add --group dev pytest` - установка
- `pytest`  - дает отчет о тестах
- `pytest --cov` - проверяет покрытие тестами

В случае необходимости проверить отдельный модуль необходи прописать команду в терминале:`flake8 src/test_masks.py`  
`flake8` - наименование используемого форматера  
`src/test_masks.py` - директория/модуль

## Описание и пример функций
## `get_mask_card_number`
Функция принимает на входе номер карты и выводит зашифровав часть номера.
### Пример:
Вход  - `1234 1234 1234 1234`

Выход - `1234 12** **** 1234`

---
## `get_mask_account`
Функция принимает на входе номер счёта и выводит зашифровав часть номера.
### Пример:
Вход  - `1234123412344134324`

Выход - `**4324`

---
## `mask_account_card`
Функция принимает на входе тип карты или счёта с номером, выводит тип карты зашифровав часть номера или счёта.
### Пример:
Вход  - `Visa Classic 6831982476737658`

Выход - `Visa Classic 6831 98** **** 7658`

---
## `get_date`
Функция принимает на входе строку с дату и время, выводит отконвертировав формат даты "ДД.ММ.ГГ".
### Пример:
Вход  - `2023-03-11T02:26:18.671407`

Выход - `11.03.2023`

---
## `filter_by_state`
Функция принимает на входе список словарей и выводит список словарей со статусом "EXECUTED".
### Пример:
Вход  - `[{"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},  
         {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"}]`  
Выход - `[{"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"}]`

---
## `filter_by_state`
Функция принимает на входе список словарей и выводит отсортированный по возрастанию дат список словарей.
### Пример:
Вход  - `[{"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"}]  
         [{"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"}]`  
Выход - `[{"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},  
         {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"}`

---

          "description": "Перевод организации",

          "to": "Счет 11776614605963066702"},  
          {"id": 939719570,
          "state": "EXECUTED",
          "date": "2018-06-30T02:08:58.425572",
          "operationAmount": {"amount": "9824.07","currency": {"name": "рубль",
                                                             "code": "RUB"}},

## `card_number_generator`
Генератор выдает номер карты в формате XXXX XXXX XXXX XXXX, где Х может быть от 0 до 9.
### Пример: 
Вход  - `2022, 2027`  
Выход - `[0000 0000 0000 2022,
          0000 0000 0000 2023,
          0000 0000 0000 2024,
          0000 0000 0000 2025,
          0000 0000 0000 2026]`
